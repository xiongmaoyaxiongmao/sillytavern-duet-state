# 双向状态

SillyTavern 1.18.0 一对一角色状态插件。独立 API 维护 char 和 user 的关系、心理、身体及生理状态，再向主聊天模型提供当前状态与演绎规则。

## 开始使用

1. 把整个 `sillytavern-duet-state` 文件夹放入酒馆的 `public/scripts/extensions/third-party/` 下，刷新酒馆页面。
2. 打开「扩展设置 → 双向状态」，填写独立 API 地址、密钥和模型。支持 OpenAI 兼容的 Chat Completions 接口，可填写基础地址（如 `https://example.com/v1`）或完整 `/chat/completions` 地址。
3. 可先点「测试连接」。勾选「启用双向状态」，点「保存设置」。当前一对一聊天会自动初始化，不需要逐项确认。
4. 输入框上方会出现「双向状态」折叠面板。展开后切换 char / user，点击数值或「编辑状态」即可修改；「原因与规则」可查看依据。

插件初装默认关闭，地址、密钥、模型均为空。不会借用主 API 设置。API 密钥保存在酒馆当前用户的扩展设置中，界面以密码框显示。

## 一轮聊天的过程

1. 用户发言进入聊天后，独立 API 仅结算尚未计算的事件。
2. 插件通过酒馆的扩展提示接口，把当前双方状态、表现和规则提供给主模型。
3. 主模型生成回复。你的明确输入优先，状态用于补充双方未写出的反应，不覆盖你已经写出的感受、动作和决定。
4. 回复结束后，独立 API 只结算本次新增剧情，不重复计算用户输入。

正常新一轮通常调用独立 API 两次。首次初始化、历史修改后的补算、手动测试连接会产生额外调用；相同输入的重新生成会复用已经确认的输入状态。

生成前判断失败时暂停本次主回复，并显示原因；生成后结算失败时保留已确认状态，可用「同步状态」重试。不会用假数值填补故障。

## 指标与模板

默认双方各有 13 项候选指标：

- 关系：好感、信任、戒备。每一方的关系指标分别指向另一方。
- 心理：心情、紧张。
- 身体：体力、疲劳、饥饿、口渴、疼痛。
- 生理：欲望、兴奋、敏感程度。

初始化会根据人物和剧情调整数值与人物倾向，也允许 API 补充少量必要的专属指标。每项都可修改名称、分组、上下限、数值、当前表现、变化规则及人物倾向；可以添加或删除，每方最多 48 项。

「编辑当前状态」只修改当前聊天。手动修改会成为后续判定的基础。

「编辑默认模板」影响之后初始化的聊天。「编辑此角色模板」优先于默认模板，同一角色的新聊天会使用它，不改变已经生成的聊天状态。角色模板里可以「载入默认模板」再保存。

## 历史与恢复

状态保存于聊天文件的 `chat_metadata.duet_state`，不修改已有记忆插件字段、角色卡或对话正文。

- 按消息内容及其前缀保存状态，每个聊天独立。
- 重生成从被替换回复之前的状态开始；与那条旧回复绑定的手动调整也随旧回复回退。
- 切换已有回复分支时恢复对应分支状态；未结算的分支会自动补算。
- 删除、编辑或回退消息会恢复有效的历史状态，并对改动后的事件补算。
- 续写仅结算追加片段；续写时的基线会保存，刷新后也可以重试失败的结算。
- 如果回退到了首次启用插件之前、没有历史快照的位置，会按当时仍存在的剧情重新初始化。
- 切换聊天或取消请求时，迟到的 API 响应不会写入新聊天。

## 上下文与边界

独立 API 接收角色卡的描述、性格、场景、示例，用户角色设定，现有状态，以及最近背景消息和全部待结算事件。默认保留最近 24 条背景消息，可在设置中调整。不会读取其他聊天、主 API 密钥、单独存储的推理字段或 MMPEA 数据。

主模型能收到经过验证的状态提示，但实际演绎效果仍取决于模型及主预设；插件无法保证模型逐句服从数值。初始化也只能依据已提供的上下文，发现不符合旧剧情时可直接修正或增加背景消息数量。

仅支持一对一聊天。群聊、静默生成、代写输入和提示词预览不会触发状态判定。插件用标准扩展接口接入，不需要改酒馆核心或另装服务端插件。

## 停用与移除

取消勾选「启用双向状态」并保存，停止后续判定和提示注入。删除插件目录并刷新可移除界面；已保存的状态保留在各自聊天元数据中，重新安装后仍可读取。
